# Finanse Domowe

Aplikacja na Androida (Kotlin) do zarządzania budżetem domowym — rejestrowanie
przychodów i wydatków oraz podgląd bieżącego stanu finansów.

## Stack

- Kotlin
- Android SDK
- Gradle

## Uruchomienie

Otwórz projekt w Android Studio i uruchom na emulatorze lub urządzeniu (**Run**).
Alternatywnie z konsoli:

```bash
./gradlew assembleDebug
```
